# Screenshots

The images in this folder are taken from Tolk's **demo build**, which runs on made-up data only:
fictional meetings, people, names and texts. They contain no real meetings, participants, accounts,
organisations or file paths.

`en\` holds the English interface (referenced by README.md), `ru\` the Russian one (README.ru.md).
Each folder has the same files, rendered at 200 % and saved as PNG without metadata:

| File | Theme | Shows |
|---|---|---|
| `list.png` | dark | The Meetings window: saved meetings by day, the meeting being saved right now at the top |
| `list-selected.png` | dark | A selected meeting: Open, Show in folder, Copy path and the menu with Copy text, Copy file, Export and Move to Recycle Bin |
| `list-search.png` | light | Search: the meetings found, each with the line of the transcript that matches |
| `flyout-saving.png` | dark | The panel above the tray icon while a meeting is being saved, the last meeting, the notice just copied |
| `welcome-3.png` | dark | First start, last step: the terms of use, how long to keep meetings, copy the notice |
| `settings-storage.png` | dark | Settings → Storage: the meetings folder, moving meetings with it, retention and the Recycle Bin |

Before adding or replacing an image, check that it was made from the demo build and shows no real
names, titles, accounts, e-mail addresses, avatars or paths.
